## ☕ Curso Atual

### Java: trabalhando com Lambdas, Streams e Spring Framework

Projeto prático **ScreenMatch** — aplicação de linha de comando que consome a API [OMDb](https://www.omdbapi.com/) para buscar e exibir informações sobre séries de TV, incluindo ranking de episódios e filtragem por data de lançamento.

#### 📖 Tópicos abordados

- Utilização do **Spring Framework** em aplicações de linha de comando
- Trabalho colaborativo com **Git e GitHub**
- Desserialização de dados JSON com a biblioteca **Jackson**
- Aplicação de boas práticas com **funções Lambda**
- Manipulação de fluxo de dados com a **Streams API**
- Implementação de **estatísticas personalizadas** (rankings, filtros e agrupamentos)
